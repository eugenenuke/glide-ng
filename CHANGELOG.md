### Changed
- **OS-Default GPU Selection (`VulkanBackend`, `OpenGLESBackend`)**: Updated `VulkanBackend::SelectPhysicalDevice()` to follow OS/loader device enumeration order when `gpu = default` instead of forcibly prioritizing discrete GPUs, and added renderer validation in `OpenGLESBackend::CreateGLContext()` so mismatched explicit GL/EGL device selections trigger the `SoftwareBackend` fallback cleanly.
- **GPU Hardware-Blended LFB Overlay Quads (`CpuLfbStaging`, `VulkanBackend`, `OpenGLESBackend`)**: Extended zero-readback GPU LFB overlay quad compositing beyond `AlphaOver` (`ONE, ZERO` / `SRC_ALPHA, ONE_MINUS_SRC_ALPHA`) to `Additive` (`ONE, ONE` / `SRC_ALPHA, ONE`), `Multiply` (`ZERO, SRC_COLOR` / `ZERO, PREFOG_COLOR` / `DST_COLOR, ZERO`), and `Screen` (`ONE, ONE_MINUS_SRC_COLOR` / `ONE_MINUS_DST_COLOR, ONE`). Eliminates per-frame `ReadbackGpuToStaging_Locked` / `vkQueueWaitIdle()` and `glReadPixels()` stalls in blended-HUD games (e.g. *Extreme Assault*) by coalescing same-mode sparse overlay writes on CPU and compositing dirty bands directly on GPU with alpha-0 fragment discard (`lfb_overlay_frag.spv` + cached blend PSOs in Vulkan; `uDiscardZeroAlpha` + dynamic `glBlendFuncSeparate` in OpenGL ES).
- **Zero-CPU-Decode Backend Cache Fast Path (`TextureManager`, `IGraphicsBackend`, `VulkanBackend`, `OpenGLESBackend`, `SoftwareBackend`)**: Added `IGraphicsBackend::TryBindCachedTexture()` so `TextureManager::DownloadMipMap()` and `EnsureTextureReady_Locked()` probe backend live/pooled content caches by metadata and `(rawDataHash, swizzledTableHash)` before running CPU texel decoding or `ReswizzleTexture_Locked()`, binding resident GPU or Software textures without BGRA8 heap allocations or redundant uploads while retaining compact raw mip levels for lazy CPU materialization on partial updates, LOD merges, snapshots, and cold misses.
- **Software Content-Addressed Decoded-Mipmap Cache (`SoftwareBackend`)**: Added a bounded `std::shared_ptr<const VirtualTexture>` LRU cache (`kMaxCachedSwTextures = 1024`, `128 MB` 64-bit / `64 MB` 32-bit cap, key `(dataHash, format, width, height, mipLevels)`) guarded by a strict leaf mutex (`m_swTexMutex`, preserving the `Software::m_mutex -> TextureManager::m_mutex -> m_swTexMutex` lock hierarchy) with `TryBindCachedTexture()` and COW-safe partial updates so paletted/address-cycling workloads skip redundant BGRA8 decoding and copying during rasterization.
- **Batched Polygon-Fan & Vertex-Array Triangle Submissions (`IGraphicsBackend`, `VulkanBackend`, `OpenGLESBackend`, `SoftwareBackend`, `GlideEntryCommon`)**: Added `IGraphicsBackend::DrawTriangleFan()` and `DrawTriangleList()` overrides across Vulkan, OpenGL ES, and Software so Glide 2.x `grDrawPolygon*` / `grDrawPolygonVertexList` and Glide 3.x `grDrawVertexArray*` / `DrawClipTriangle()` acquire each backend mutex, flush LFB staging, resolve pipeline/state, and check front-buffer mutation once per polygon/draw call rather than per decomposed triangle.
- **OpenGL ES / WGL Content-Addressed `GLuint` Texture Cache (`OpenGLESBackend`, `OpenGLESTextures`)**: Added a bounded `std::shared_ptr` live + LRU idle `GLuint` texture cache (`kMaxCachedGlesTextures = 1024`, `128 MB` 64-bit / `64 MB` 32-bit VRAM cap, key `(dataHash, internalFormat, width, height, mipLevels)`) with `TryBindCachedTexture()`, context-safe deferred GL texture deletion (`FlushPendingGlesTexDeletes_Locked`), warm idle-cache preservation below capacity, and COW safety on `UploadTexturePartial` / `CommitGpuTextureBuffer` (closing the high-churn paletted upload gap vs Vulkan).
- **OpenGL ES / WGL Per-Draw State Caching & Headless `GLsync` Frame Ring (`OpenGLESBackend`, `OpenGLESTextures`, `OpenGLESDraw`, `OpenGLESShaders`, `Win32GlLoader`)**: Replaced synchronous headless `glFinish()` with a 2-slot `GLsync` fence ring (`glFenceSync` / `glClientWaitSync` + `glFlush`), eliminated redundant `glSamplerParameteri()` and `uTextureEnabled` / `uTexLodBias` / `uTexSampleLodBias` uniform uploads across unchanged-sampler texture binds via `kGlesDirtyTexLodBias` and cached uniform state, and loaded `glFlush` / `GLsync` core entry points dynamically in the Win32 WGL loader.
- **Vulkan Headless `SwapBuffers()` Readback Elimination & WC-Safe `GR_ORIGIN_LOWER_LEFT` Vertex Writes (`VulkanBackend`, `VulkanDraw`)**: Removed the unused per-frame `copyImageToBuffer` GPU-to-CPU PCIe readback DMA from headless `VulkanBackend::SwapBuffers()` (keeping `m_headlessPixelBuffers` populated on demand by `VulkanLfb.cpp` for LFB reads and `FX_GLIDE_SNAPSHOT`), and converted `DrawTriangleFan()` / `DrawTriangleList()` `GR_ORIGIN_LOWER_LEFT` Y-flips to write-combining-safe sequential stores without reading back from mapped GPU memory.
- **Centralized Hash & Hardware/ABI Constants (`HashUtils.h`, `GlideConstants.h`)**: Consolidated duplicated FNV-1a / SplitMix64 / golden-ratio hash constants and `HashCombine` / `MixBytes64` helpers into [`src/core/HashUtils.h`](src/core/HashUtils.h), and replaced recurring unnamed magic literals (unbound TMU sentinel, VSA-100 extended combiner active bit, LFB buffer/ZA16 codes, 24-bit depth scaling, byte-broadcast multipliers, Vulkan push-constant flag bits, GL handle sentinels, IEEE-754 vertex snap biases, and x86 CPUID leaves) with documented named constants across `src/core/`, `src/backends/`, and `src/glide3/`.
- **Vulkan Content-Addressed Texture Cache & Bucketed Reuse Pool (`VulkanBackend`, `VulkanTextures`)**:
  - Replaced `VulkanBackend`'s 128-entry linear `m_texturePool` with a bounded `O(1)` bucketed free-pool (`kMaxPooledTextures = 1024`, `128 MB` 64-bit / `64 MB` 32-bit VRAM cap) paired with a `std::shared_ptr` content-addressed `VkImage` cache covering both live/in-flight and idle pooled textures (keyed by `(dataHash, format, width, height, mipLevels)`). Eliminates per-frame `vkCreateImage` / `vkAllocateMemory` / `vkFreeMemory` thrash on high-churn paletted workloads (e.g. *Blood* `3DFX.EXE`'s ~190 shade-palette uploads/frame) while preserving COW safety on `UploadTexturePartial` and `CommitGpuTextureBuffer`.
  - Added missing `GLIDE_CPU_SCOPE(CpuBucket::Tex)` telemetry attribution to `grTexDownloadMipMapLevel()` (`glide2x` / `glide` 2.11 / `glide3x`) and `guMPTexSource()`.
- **Low-Overhead Invariant-TSC Telemetry Clock (`TelemetryManager`, `CpuBucketScope`)**: Switched `CpuBucketScope` on x86/x86_64 hosts with architectural Invariant TSC (`CPUID 0x80000007` EDX bit 8) from per-call `std::chrono::steady_clock::now()` to inline `rdtsc` tick accumulation calibrated against `steady_clock` (with automatic fallback on non-x86/non-invariant CPUs). Eliminates `~17×` `GLIDE_NG_PERF_LOG` observer slowdown on Linux systems running the `hpet` clocksource while keeping zero startup cost when perf logging is disabled.

### Fixed
- **Small-Region OpenMP Guard & Extended Blend Factors in `CpuLfbStaging`**: Guarded `CpuLfbStaging::RunWriteLFBParallel` with an explicit pixel-count threshold (`> 64000` pixels, matching `SoftwareBackendBase` / `SoftwareBackend`) to eliminate cross-CCD OpenMP thread-wake futex/barrier storms on small LFB HUD strips, and added `EvalRgbBlendFactor` handling for `GR_BLEND_PREFOG_COLOR` (`15`), `GR_BLEND_ALPHA_SATURATE` (`15`), `GR_BLEND_SAME_COLOR_EXT` (`8`), and `GR_BLEND_ONE_MINUS_SAME_COLOR_EXT` (`9`).
- **Dual-CCD `rdtscp` Telemetry Calibration & Per-CPU Offset Normalization (`TelemetryManager`, `CpuBucketScope`)**: Replaced bare `rdtsc` with `rdtscp` (`EDX` + `ECX` processor ID) paired with short same-CPU spin-wait median calibration and lazy per-CPU TSC offset normalization in `TelemetryManager` / `CpuBucketScope`. Eliminates false calibration rejects on multi-CCD CPUs (which caused fallback to slow OS `hpet` clocksource reads under `GLIDE_NG_PERF_LOG`) as well as multi-second frame spikes from cross-CCD thread migrations.
- **Win32 Embedded `Alt+Tab` Focus/Minimize, `WaitMessage()` Wakeup & Startup Splash Resize (`NativeSurfaceHost`, `GlideEntryCommon`)**:
  - Added `NativeSurfaceHost::ShouldForceWin32SwpNoActivate()` in `WM_WINDOWPOSCHANGING` to force `SWP_NOACTIVATE` when deactivated fullscreen titles call `SetWindowPos(HWND_BOTTOM)` without it (preventing synchronous focus re-activation loops), and `ComputeRestoredWin32Styles()` to preserve live `WS_VISIBLE` / `WS_MINIMIZE` / `WS_EX_TOPMOST` state on detach instead of restoring stale startup topmost flags.
  - Posted a benign `WM_NULL` message on reactivation so games sleeping in `WaitMessage()` wake up immediately after synchronous `WM_ACTIVATEAPP` / `WM_SETFOCUS` dispatch, and avoided unexpectedly restoring minimized (`WS_MINIMIZE`) windows unless explicitly re-activated (`restoreIfIconic`).
  - Tracked blocking automatic startup splashes via `NativeSurfaceHost::SetAutoSplashActive()` so `PollEvents()` pumps non-destructive `PeekMessage(PM_NOREMOVE)` under Wine/Wayland/XWayland and commits the borderless-fullscreen resize during the splash instead of deferring until `grSstWinOpen()` returns.

### Fixed
- **Direct `GR_BUFFER_FRONTBUFFER` Trailing-Edge Scanout (`FrontBufferFlushTimer`, `VulkanBackend`, `OpenGLESBackend`, `SoftwareBackend`)**:
  - Added lazy-spawned trailing-edge timer [`src/backends/FrontBufferFlushTimer.h`](src/backends/FrontBufferFlushTimer.h) (`zero` background threads for headless or double-buffered games) wired into front-buffer mutations (`WriteLFB`, `ClearBufferExt`, `DrawPoint`, `DrawLine`, `DrawTriangle`) across **Vulkan**, **OpenGL ES / WGL**, and **Software** backends. Titles that render menus, cursor highlights, and typewriter briefings directly into `GR_BUFFER_FRONTBUFFER` without calling `grBufferSwap()` (e.g. *Descent II* `D2_3DFX.EXE`) now present bursts cleanly within ~33 ms instead of sitting blank until the next swap.
  - Updated `VulkanBackend::PresentFrontBuffer_Locked()` to materialize deferred clear state before blitting and recycle the completed frame slot's staging/vertex-ring offsets and retired textures after `waitForFences`, preventing `Dynamic Vertex Buffer slot overflow` stalls inside un-swapped menu loops.
  - Added cross-thread EGL/WGL context release guards (`ScopedFrontContextRelease` / `ReleaseFrontPresentContext_Locked()`, saving/restoring `eglBindAPI()`) in `OpenGLESBackend` so the background flush thread never hits `EGL_BAD_ACCESS` (`0x3002`) / `ERROR_BUSY` when taking over presentation.
- **Subnormal IEEE-754 `oow` Sanitization (`VertexLayout::SanitizePositiveOow`)**:
  - Tightened `VertexLayout::SanitizePositiveOow(float)` from `f > 0.0f` to **`f >= FLT_MIN`** (`~1.175e-38f`). Uninitialized stack integers left in `GrVertex.oow` (e.g., `14` → `1.93715e-41f`) previously passed the CPU `> 0.0f` check and were then flushed to `0.0` by GPU FTZ/DAZ on **Vulkan** and **OpenGL ES**, causing the `divW0 <= 0.0` fragment guard to discard *Descent II*'s `Tab` 3D wireframe automap tunnels and diagonally clip HUD shield readout boxes (`grColorMask(FXTRUE, FXTRUE)` with stale `grAlphaCombine(..., TEXTURE)`).
- **`TEXUMA` (`GR_TEXTURE_UMA_EXT`) Pre-Window Retention (`glide3x` / `GlideEntryCommon`)**:
  - Stopped `ConfigureTmuMemoryLimits()` from resetting `TextureManager::SetUmaMode()` inside `grSstWinOpen()` / `grSstWinOpenExt()`. Applications that follow the 3dfx `TEXUMA` spec and call `grEnable(GR_TEXTURE_UMA_EXT)` between `grGlideInit()` and `grSstWinOpen*()` now retain unified texture memory instead of having it reset to disabled on window attach (eliminating cross-TMU cache misses that fell back to the 1×1 white placeholder texture). Initial `FX_GLIDE_TEXTURE_UMA` / `[glide] texture_uma` state is still applied once at `grGlideInit()` time so stale state does not leak across sessions.
  - Updated `grGet(GR_MEMORY_TMU)` on Glide 3.x to double the reported TMU size when `TEXUMA` is active on dual-TMU profiles (matching `grTexMaxAddress()` and `h5/glide3/src/gsst.c` / `diget.c`).
  - Updated mid-mode `TEXTUREBUFFER` auto-commit in `grTexSource()` to trigger cross-TMU when `TEXUMA` is active, and ensured `grEnable()`/`grDisable()` invoke `EnsureEngineInitialized()` before reading the active card model.
